# Финансы — учёт доходов и расходов

**Как открыть:** скачайте файл [`finance.html`](finance.html) (на GitHub: открыть файл → кнопка «Download raw file»)
и откройте его двойным кликом в браузере (Chrome, Edge, Safari). Интернет не нужен.

Данные хранятся в браузере на этом компьютере. Регулярно делайте копию: «Настройки» → «Скачать копию».

- Что и как устроено — [docs/SPEC.md](docs/SPEC.md)
- Правила разработки — [CLAUDE.md](CLAUDE.md)
