# CLAUDE.md

## О проекте
Личный учёт доходов и расходов: веб-страничка, которая открывается в браузере.
Сейчас это бета-тест перед большим проектом. Цель: переписать старую сырую версию
(много багов, неудобный интерфейс, долгое добавление операций) и перенести в новую
то, что в старой было удобным.

### План работ
1. **Анализ старой странички.** Хорошие и плохие фичи, что оставить, что убрать, общая оценка.
2. **Новая страничка.** Пишем с нуля, переносим удачные механики.

## Владелец проекта
- Владелец **не разработчик**. Объясняй простым языком, без жаргона. Если без термина
  не обойтись, поясни его в одном предложении.
- Технические решения (язык, библиотеки, структура) принимает Claude. Выбор нужно коротко
  объяснить: что выбрано и почему это хорошо для владельца.
- Продуктовые решения (что умеет приложение, как выглядит, какие функции важнее)
  принимает владелец. При развилке предложи 2–3 варианта и свою рекомендацию.
- Общение, комментарии в коде и сообщения коммитов пишутся **на русском**.

## Как работаем
- Работаем по этапам. Перед большим изменением дай короткий план и дождись «ок».
- После каждого шага опиши, что сделано и как это проверить (что открыть, куда нажать).
- Перед сдачей проверяй страницу в браузере сам: открывается, работает, нет ошибок.
- Данные пользователя (его операции) нельзя терять. Любое изменение формата хранения
  должно сохранять старые записи. В приложении должна быть резервная копия (экспорт/импорт).
- Коммиты делаются небольшими и пушатся после каждого готового шага, чтобы работа не пропала.

## Технологии (предварительно, уточним после анализа)
- Один HTML-файл без сборки и установки: его можно открыть двойным кликом или
  разместить на GitHub Pages.
- Данные хранятся в браузере (localStorage), резервная копия делается через экспорт в файл.
- Страница должна быть удобной на телефоне.

## Структура репозитория
- `legacy/` — старая версия странички (только для анализа, не правим).
- `index.html` — новая версия.
